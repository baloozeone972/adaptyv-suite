The problem

Adaptyv is a lab that tests proteins for its customers: you send "recipes", it makes them, measures whether they work (how strongly they stick, whether they dissolve, whether they're stable), and sends the results back. Around that lab there are the same recurring headaches — a results file nobody can read, good money spent on designs that were never going to work, days lost to reviewing charts by hand. This suite is a toolbox that tackles them, one at a time.

The brief was open, so the material set the scope. Adaptyv's own docs and posts name the frictions: a binding data package shipped with no reader; a published expression workflow nobody implemented; a 21-day turnaround spending days 16–21 on manual QC; being the only CRO with an API yet still breaking reproducible pipelines at the lab door. Each tool targets a documented friction — not a guessed one — and they share primitives (contracts, kinetics, pricing, guardrails, reporting), so they live in one uv workspace on a single foundation package, adaptyv-core.

The principle: honesty by construction

Adaptyv publishes confidence intervals and negative results. The suite holds itself to the same bar.

Never a lonely number. Every result comes with its margin of error, like a poll given "±2%". We say what we don't know. Each tool lists, in plain text, what it does not claim. Fake data is labelled fake. Since a candidate has no access to the real data, every demo runs on made-up data — and it says so, in big letters, on every report.

CIs everywhere. Performance metrics ship a bootstrap interval and n. Declared limitations. Each package has a docs/limitations.md. DataSource stamped. Every report carries a synthetic / real / foundry banner. Refusal to fabricate. When the kinetics fit can't identify an off-rate (too little dissociation), the tool flags it rather than printing a confident KD.

How it fits together

All the tools share one "toolbox" of basic parts (a common vocabulary, the maths, the report style, the safety rails). So they understand each other and never contradict — "a protein too greasy to dissolve" means the same thing everywhere.

A uv workspace. Dependencies point strictly downward: every tool depends on adaptyv-core; a few tool→tool edges never cycle (adaptyv-kinetics → protviz, sensorgram-triage → adaptyv-kinetics, dbtl-agent → binder-triage). Contracts (Pydantic v2) are frozen first, so each package is built and tested in isolation against synthetic fixtures.
